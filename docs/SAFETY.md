# Seguridad y alcance

## Principio

FitPlanner AI es una herramienta educativa y de organización. No diagnostica, no trata y no promete que un ejercicio sea seguro para una lesión concreta.

## Cribado de salud

En el onboarding se pregunta por:

- Lesión actual o limitación de movimiento.
- Ejercicios indicados a evitar.
- Condición de salud que afecte a la actividad física.
- Dolor, mareos, desmayos, dolor de pecho o dificultad respiratoria inusual durante el ejercicio.
- Recomendación médica que deba respetarse.
- Opción “Prefiero no responder”.

## Bloqueos

La generación automática se bloquea si:

- Hay síntomas de alarma.
- Hay una recomendación médica declarada.

En esos casos la app:

- No genera una rutina.
- Explica la precaución.
- Recomienda valoración profesional.
- Permite seguir consultando el catálogo educativo.

## Lesiones declaradas

Si el usuario declara una lesión o limitación:

- Se muestran avisos.
- Se filtran ejercicios con etiquetas de restricción coincidentes.
- Se mantiene lenguaje prudente: “adaptado a lo declarado”, nunca “seguro para tu lesión”.
- El plan se presenta para revisión.

## Dolor durante el entrenamiento

La app recuerda detenerse ante dolor, mareo, desmayo, dolor de pecho o dificultad respiratoria. La revisión semanal permite indicar molestias; si las hay, el motor reduce volumen y descanso y no aumenta cargas. Si el dolor persiste, se recomienda consultar.

## Progresión

- No se fuerza el fallo.
- No se suben pesos automáticamente.
- Los aumentos son sugerencias.
- El volumen se limita por nivel.
- Se evita programar más de 3 días consecutivos.

## Privacidad

- Datos locales.
- Sin cuentas ni analytics.
- Copia de seguridad desactivada.
- Clave de IA cifrada.
- La IA opcional recibe solo un resumen anonimizado.
- El usuario puede borrar el historial de planes y reiniciar el asistente.

## IA

- Desactivada por defecto.
- Requiere consentimiento explícito.
- No recibe nombre, edad exacta, peso ni notas médicas.
- La respuesta se valida localmente.
- Si la IA falla o propone algo incompatible, se descarta.
- La IA no puede desbloquear un plan bloqueado por seguridad.

## Limitaciones

- No hay revisión clínica del contenido.
- Las animaciones son simplificadas.
- No hay integración con wearables ni datos médicos.
- No es un servicio de emergencia.
